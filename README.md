# 今朝 Jinzhao

**把今天，过得井井有条。**

Mac 上的「今天」应用：日历、任务、习惯合一，为中国人的日历习惯而做。
农历、节气、干支、法定节假日与调休，全都算得明明白白。
液态玻璃界面，深 / 浅双外观，数据只存本机、断网可用。免费开源。

## 下载

系统要求：**macOS 26 及以上**（Apple 芯片与 Intel 均可）。

- [GitHub 下载](https://github.com/hanson-zz/Jinzhao/releases) — 到 Releases 页选最新版，下载 `Jinzhao-x.y.z.dmg`
- 国内镜像 — 准备中，开通后在这里放直达链接

## 打不开怎么办

今朝尚未购买苹果开发者签名，第一次打开时 macOS 可能提示「无法验证开发者」。
这是对未签名应用的例行拦截，不是软件损坏。两种放行方法，任选其一：

**方法一**：先双击打开一次（看到提示后关掉），再打开「系统设置 > 隐私与安全性」，
往下滚动，点「仍要打开」。

**方法二**：打开「终端」，运行：

```
xattr -dr com.apple.quarantine /Applications/今朝.app
```

DMG 里也附了同一份说明（打不开怎么办.txt）。

## 功能

- **今天页**：日期条带农历、节气、干支，休 / 班角标，调休上班提醒
- **任务**：子任务、重要标记、文件夹；截止时间支持中文输入，
  打「明天下午三点开会」会自动认出时间，回车只留下「开会」
- **习惯**：打卡圆环、连续天数
- **日历**：月视图读写苹果日历，腾讯会议 / 飞书 / Zoom 等会议链接一键入会
- **即将到来**：未来 14 天的日程和任务
- **收件箱**：⌘N 随手记，先记下再分流；⌘K 快速搜索
- **下一个假期**：带农历和休 / 班标记的小日历 + 假期倒计时，节假日数据可自动更新

公测期间全部功能开放。笔记页、习惯统计页、时间轴、看板即将推出。

## 数据与隐私

- 所有数据保存在本机 `~/Library/Application Support/Jinzhao`，不联网上传
- 唯一联网行为：每天静默检查一次节假日数据更新（可断网使用，不影响功能）
